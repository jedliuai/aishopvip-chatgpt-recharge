## 先分清你要办理的服务

“ChatGPT 充值”在日常表达中可能指第一次订阅、已有会员续费，或切换到其他套餐。下单时应以商品实际提供的服务为准，不能只看标题中出现了 Plus 或 Pro 就认为适合自己。

| 你的情况 | 下单前主要确认 |
| --- | --- |
| 账号目前没有订阅 | 所选商品是否支持首次开通，需要什么账号条件 |
| 会员还没到期 | 是否支持当前状态下续费，还是需要等到期后办理 |
| 准备从一个套餐换到另一个套餐 | 是否支持升级或转换，原订阅的地区与来源是否符合要求 |
| 之前通过其他方式订阅 | 原订阅渠道是否影响本次办理 |
| 对自己的订阅情况不确定 | 先在账号中确认，再向网站客服咨询适用商品 |

网站展示的套餐和办理条件可能变化，本指南不替代具体商品说明。

## 第二步：核对四项信息

1. **套餐名称与周期。** 确认自己准备购买的会员类型、服务周期和具体规格。
2. **账号适用条件。** 核对已有订阅、订阅来源、地区和开通状态等页面要求。
3. **价格与交付方式。** 以所选规格和下单页面为准，同时阅读付款后的操作说明。
4. **续费与售后。** 查看当前商品是否支持续费，以及出现办理异常时的处理入口。

例如，2026-10-21 核对的 Plus 商品页写明为客户本人账号开通订阅，并提示原订阅未到期时不能覆盖充值。这个例子说明了为什么要先读条件，不表示所有商品都使用同一套规则。

## 第三步：按网站指引下单

确认条件后，按商品详情页和网站下单流程操作。网站当时的页面提供了商品规格、购买数量和购买入口；实际需要填写的信息、支付渠道与交付步骤，以当前页面为准。

保存订单信息和当时的商品说明，便于之后查询。账号信息及订单详情应在网站指定的服务渠道处理，不要填写到公开 GitHub Issues 中。

## 第四步：确认交付结果

按订单页面的指引完成必要步骤后，在自己的 ChatGPT 账号内查看订阅是否变成预期状态。不要只凭付款成功就判断订阅已经完成。

如果状态没有更新：

1. 核对是否还有订单要求的后续操作未完成。
2. 查看商品说明、订单提示和 [最新公告](https://aishopvip.com/notice)。
3. 通过网站客服说明订单情况，确认处理进度后再决定后续操作。

不要在未查清原订单状态时重复购买，以免产生多笔订单。

## 续费与升级前需要确认什么

- 当前账号是什么套餐，是否仍在有效期内？
- 原来的订阅来源和地区是否满足新商品要求？
- 所选商品是首次开通、续费专用，还是支持升级？
- 商品是否要求在指定时间或状态下办理？

其中任何一项不明确，都可以先通过网站客服确认对应商品。具体条件应查看当次商品页面，不能沿用上一次购买时的规则。
